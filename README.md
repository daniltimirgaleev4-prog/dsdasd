# GitHub User Finder

## Автор 
Тимиргалеев Данил 

## Описание
GitHub User Finder - это desktop-приложение с графическим интерфейсом для поиска пользователей GitHub. Приложение позволяет:
- Искать пользователей GitHub по логину
- Просматривать результаты поиска в удобном табличном виде
- Добавлять пользователей в избранное
- Сохранять избранных пользователей локально в JSON-файл
- Управлять списком избранных (удалять отдельных пользователей или очищать весь список)
